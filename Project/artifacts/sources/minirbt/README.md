# MiniRBT pretrained model

This directory contains source materials for the Chinese MiniRBT pretrained model. The source repository is available at [iflytek/MiniRBT](https://github.com/iflytek/MiniRBT).

The upstream documentation describes Whole Word Masking and knowledge distillation using the [TextBrewer toolkit](https://github.com/airaria/TextBrewer). Use BERT-compatible functions to load the model.
